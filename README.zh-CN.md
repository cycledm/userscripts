# Userscripts

由 CycleDM 个人开发和维护的油猴用户脚本集合，用于增强网站功能、改善网页使用体验，以及自动化常见网页操作。

脚本以个人需求为导向，可能并不适用于所有用户或环境。各脚本会根据已有的可靠依据，分别说明其与 Tampermonkey、Violentmonkey 等用户脚本管理器的兼容情况。
